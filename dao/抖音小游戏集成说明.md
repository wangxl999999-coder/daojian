# 抖音小游戏功能集成说明

## 已创建/修改的文件列表

### 1. 广告相关文件
- `assets/Script/platform/douyinAdManager.js` - 抖音广告管理器
  - 激励视频广告
  - Banner广告
  - 插屏广告

### 2. 任务系统文件
- `assets/Script/panel/taskPanelUIEvent.js` - 任务面板UI事件
  - 每日任务列表
  - 任务进度显示
  - 领取奖励功能
  - 观看视频任务

### 3. 侧边栏功能文件
- `assets/Script/platform/douyinSidebarManager.js` - 侧边栏管理器
  - 检查侧边栏收藏状态
  - 自动监测侧边栏状态
- `assets/Script/panel/sidebarGuidePanelUIEvent.js` - 侧边栏引导弹窗
  - 引导用户添加到侧边栏
  - 可关闭弹窗
  - 动画引导效果

### 4. 平台适配文件
- `assets/Script/platform/douyinPlatform.js` - 抖音平台核心适配
  - 用户信息获取
  - 分享功能
  - 前后台事件监听
  - 振动反馈
- `build-templates/bytedance/game.js` - 抖音小游戏构建模板

### 5. 修改的核心文件
- `assets/Script/panel/mainPanelUIEvent.js` - 主面板
  - 添加任务入口按钮
  - 添加侧边栏入口按钮
  - 添加任务红点提示
  - 集成抖音平台初始化
- `assets/Script/component/startGame.js` - 游戏启动
  - 抖音平台初始化
- `assets/Script/ui/gameOverPanel/gameOverPanelUIEvent.js` - 游戏结束面板
  - 每日任务统计更新
  - 跨天重置任务

## 需要在Cocos Creator中配置的内容

### 1. 任务面板 Prefab (taskPanel)
需要创建以下节点并绑定对应的属性：
- `taskListContent` - 任务列表容器节点
- `taskItemPrefab` - 任务项预制体
  - 每个任务项需要包含：
  - `title` - 任务标题Label
  - `desc` - 任务描述Label
  - `reward` - 奖励数量Label
  - `progress` - 进度条组件
  - `progressLabel` - 进度文字Label (x/x)
  - `btnGo` - 前往按钮
  - `btnClaim` - 领取按钮
  - `completedMark` - 已完成标记
  - `btnClose` - 关闭按钮

### 2. 侧边栏引导面板 Prefab (sidebarGuidePanel)
需要创建以下节点并绑定对应的属性：
- `btnClose` - 关闭按钮
- `btnGoSidebar` - 前往侧边栏按钮
- `guideText` - 引导文字Label
- `animationNode` - 动画节点

### 3. 主面板 (mainPanel) 添加的节点
需要在mainPanel中添加以下节点并绑定到属性：
- `btnTask` - 任务入口按钮
- `btnSidebar` - 侧边栏入口按钮
- `nodeTaskRedDot` - 任务红点提示节点

## 抖音小游戏广告位ID配置

在 `douyinAdManager.js` 中需要替换真实的广告位ID：
```javascript
// 激励视频广告位ID
adUnitId: 'YOUR_REWARDED_VIDEO_AD_UNIT_ID'

// Banner广告位ID  
adUnitId: 'YOUR_BANNER_AD_UNIT_ID'

```

## 任务系统说明

### 已实现的每日任务：
1. **每日登录** - 首次登录自动完成，奖励100金币
2. **对战3局** - 完成3局游戏，奖励200金币
3. **观看视频** - 观看1次激励视频，奖励150金币
4. **获得第一名** - 游戏中获得第1名，奖励300金币

### 任务数据存储字段：
- `todayPlayCount` - 今日游戏次数
- `todayWinCount` - 今日第一名次数
- `todayWatchAdCount` - 今日观看广告次数
- `dailyLoginCompleted` - 今日登录完成
- `dailyLoginClaimed` - 登录奖励已领取
- `play3GameClaimed` - 3局游戏奖励已领取
- `watchAdClaimed` - 视频奖励已领取
- `reachTop1Claimed` - 第一名奖励已领取
- `lastLoginDate` - 最后登录日期（用于跨天重置）

## 侧边栏复访功能说明

1. **自动检测**：游戏启动时自动检测是否已添加到侧边栏
2. **引导弹窗**：未添加时自动弹出引导弹窗（仅显示1次）
3. **手动入口**：主面板提供侧边栏入口按钮，可随时触发引导
4. **状态监测**：每10秒检测一次侧边栏状态变化

## 打包发布流程

### 1. Cocos Creator 构建
1. 打开项目
2. 点击 项目 -> 构建发布
3. 平台选择「字节跳动小游戏」
4. 设置APPID（需要在字节跳动开发者平台申请）
5. 点击「构建」

### 2. 字节跳动开发者工具
1. 打开字节跳动开发者工具
2. 选择「导入项目」
3. 选择构建后的目录（一般在 `build/bytedance-mini-game`）
4. 填写AppID
5. 进入项目后进行测试和上传

## 注意事项

1. **广告测试**：
   - 测试期间使用测试广告位ID
   - 上线前替换为正式广告位ID
   - 确保广告展示频率符合平台规范

2. **审核注意**：
   - 确保不包含任何敏感内容
   - 激励视频奖励需要明确告知用户
   - 侧边栏引导不能强制用户

3. **数据存储**：
   - 任务数据需要持久化存储
   - 建议使用 `cc.sys.localStorage` 进行存储
   - 跨天重置逻辑需要处理时区问题

4. **兼容性**：
   - 所有抖音API调用都有try-catch保护
   - 非抖音环境下有模拟逻辑
   - 确保在Web和其他平台也能正常运行

## 测试建议

1. 先在Cocos Creator模拟器中测试功能逻辑
2. 再在字节跳动开发者工具中测试平台API
3. 使用真机测试广告和侧边栏功能
4. 测试跨天重置逻辑（可以修改系统时间测试）
5. 测试任务进度和奖励领取流程

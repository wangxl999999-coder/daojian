## 游戏介绍
- **刀剑争霸**
1.本游戏属于休闲竞技类型游戏，分别为玩家和AI共同参与。
2.主要目的是收集更多的刀剑，击杀对手，活到最后。
3.名次越高得到金币越多，金币可以用来解锁更多的皮肤。

## 操作说明
* 手指长按屏幕，左右滑动控制角色移动的移动方向
* 玩家可以在屏幕的任意处滑动控制角色移动。
* 松开手指，玩家停留在原地进入防御状态。
* 控制角色拾取地上的刀剑，并在刀剑充足时靠近对手击杀。
